# Backend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the REST API (Express + MongoDB) for the tech-store e-commerce site, fully tested against a real MongoDB replica set.

**Architecture:** Layered backend: Route → Controller → Service → Model. Routes only wire URL + middleware to a controller. Controllers parse/validate input (zod), call exactly one service function, and shape the HTTP response. Services hold all business rules, know nothing about `req`/`res`, and own transactions. Models are Mongoose schemas only.

**Tech Stack:** Node.js (ESM, JavaScript), Express 5, Mongoose 8, zod 3, bcryptjs, jose (JWT), cookie-parser, multer, `node:test` + supertest, MongoDB 7 in Docker (single-node replica set).

> The frontend (Next.js) gets its own plan, written after this backend works. See spec `docs/superpowers/specs/2026-10-31-webbanhang-design.md`.

## Global Constraints

- Language: JavaScript only, ESM (`"type": "module"`), imports must include the `.js` extension.
- Money: integer VND everywhere (no floats). Default shipping fee `30000`, from env `SHIPPING_FEE`.
- Order status flow: `pending → confirmed → shipping → delivered`; `cancelled` only from `pending`/`confirmed` and only while `paymentStatus !== 'paid'`.
- Payment: `cod` starts `unpaid`, `bank` starts `pending`; only an admin sets `paid`. A `bank` order cannot be `confirmed` until `paid`.
- Revenue = Σ(`total − shippingFee`) of orders with `status='delivered'` AND `paymentStatus='paid'`, bucketed by `deliveredAt`.
- Roles: `customer`, `admin`. Public register only creates `customer`.
- Password min length 8. Product images ≤ 2 MB, only `image/jpeg`, `image/png`, `image/webp`.
- Error body is always `{ code, message }` (plus `fieldErrors` for validation). Never return `passwordHash`.
- Auth: JWT in httpOnly cookie named `token`, `sameSite=lax`, 7 days. API is mounted under `/api`.
- Tests run against a real MongoDB replica set (no DB mocks) using database `webbanhang_test`; test files run one at a time.
- Search uses an escaped, case-insensitive regex on `name` and `brand` (substring match). This replaces the text index mentioned in the spec.

```js
export class AppError extends Error {
  constructor(status, code, message, fieldErrors) {
    super(message);

export function conflictIfDuplicate(err, message) {
```

`backend/src/middleware/errorHandler.js`:

```js
import { ZodError } from 'zod';
import { AppError } from '../lib/errors.js';

export function errorHandler(err, req, res, next) {
  if (err instanceof AppError) {
    const body = { code: err.code, message: err.message };
    if (err.fieldErrors) body.fieldErrors = err.fieldErrors;
    return res.status(err.status).json(body);
  }
  if (err instanceof ZodError) {
    return res.status(400).json({
      code: 'VALIDATION',
      message: 'Dữ liệu không hợp lệ',
      fieldErrors: err.flatten().fieldErrors,
    });
  }
  if (err.type === 'entity.parse.failed') {
    return res.status(400).json({ code: 'BAD_JSON', message: 'JSON không hợp lệ' });
  }
  if (err.code === 'LIMIT_FILE_SIZE') {
    return res.status(413).json({ code: 'FILE_TOO_LARGE', message: 'Ảnh tối đa 2 MB' });
  }
  console.error(err);
  res.status(500).json({ code: 'INTERNAL', message: 'Lỗi máy chủ' });
}
```

```js
import { SignJWT, jwtVerify } from 'jose';
import { config } from '../config.js';

const secret = () => new TextEncoder().encode(config.jwtSecret);

export const signToken = (user) =>
  new SignJWT({ role: user.role })
    .setSubject(String(user._id))
    .setProtectedHeader({ alg: 'HS256' })
    .setExpirationTime('7d')
    .sign(secret());

export async function verifyToken(token) {
  const { payload } = await jwtVerify(token, secret());
  return payload;
}
```

`backend/src/middleware/auth.js`:

```js
import { AppError } from '../lib/errors.js';
import { verifyToken } from '../lib/auth.js';
import { User } from '../models/User.js';

export async function authenticate(req, res, next) {
  const token = req.cookies?.token;
  if (!token) throw new AppError(401, 'UNAUTHENTICATED', 'Cần đăng nhập');
  let payload;
  try {
    payload = await verifyToken(token);
  } catch {
    throw new AppError(401, 'UNAUTHENTICATED', 'Phiên đăng nhập không hợp lệ');
  }
  const user = await User.findById(payload.sub).select('role isActive');
  if (!user || !user.isActive) {
    throw new AppError(401, 'UNAUTHENTICATED', 'Phiên đăng nhập không hợp lệ');
  }
  req.user = { id: String(user._id), role: user.role };
  next();
}

export const requireRole = (role) => (req, res, next) => {
  if (req.user?.role !== role) throw new AppError(403, 'FORBIDDEN', 'Không có quyền truy cập');
  next();
};

export const requireAdmin = [authenticate, requireRole('admin')];
```

`backend/src/services/authService.js`:

```js
import bcrypt from 'bcryptjs';
import { User } from '../models/User.js';
import { AppError } from '../lib/errors.js';
import { signToken } from '../lib/auth.js';

export const toDTO = (u) => ({
  id: String(u._id),
  email: u.email,
  fullName: u.fullName,
  phone: u.phone,
  role: u.role,
  isActive: u.isActive,
});

export async function register({ email, password, fullName, phone }) {
  const passwordHash = await bcrypt.hash(password, 10);
  try {
    const user = await User.create({ email, passwordHash, fullName, phone, role: 'customer' });
    return toDTO(user);
  } catch (err) {
    if (err.code === 11000) throw new AppError(409, 'EMAIL_TAKEN', 'Email đã được đăng ký');
    throw err;
  }
}

export async function login({ email, password }) {
  const user = await User.findOne({ email });
  if (!user || !(await bcrypt.compare(password, user.passwordHash))) {
    throw new AppError(401, 'INVALID_CREDENTIALS', 'Email hoặc mật khẩu không đúng');
  }
  if (!user.isActive) throw new AppError(403, 'ACCOUNT_LOCKED', 'Tài khoản đã bị khóa');
  return { user: toDTO(user), token: await signToken(user) };
}

export async function getById(id) {
  const user = await User.findById(id);
  if (!user) throw new AppError(404, 'NOT_FOUND', 'Không tìm thấy người dùng');
  return toDTO(user);
}
```

`backend/src/controllers/authController.js`:

```js
import * as authService from '../services/authService.js';
import { registerSchema, loginSchema } from '../validators/auth.js';
import { config } from '../config.js';

const cookieOptions = {
  httpOnly: true,
  sameSite: 'lax',
  secure: config.env === 'production',
  maxAge: 7 * 24 * 60 * 60 * 1000,
};

export async function register(req, res) {
  const user = await authService.register(registerSchema.parse(req.body));
  res.status(201).json(user);
}

export async function login(req, res) {
  const { user, token } = await authService.login(loginSchema.parse(req.body));
  res.cookie('token', token, cookieOptions).json(user);
}

export function logout(req, res) {
  res.clearCookie('token', { ...cookieOptions, maxAge: undefined }).status(204).end();
}

export async function me(req, res) {
  res.json(await authService.getById(req.user.id));
}
```

```js
export async function update(id, { name, isActive }) {
  const patch = {};
  if (name !== undefined) Object.assign(patch, { name, slug: slugify(name) });
  if (isActive !== undefined) patch.isActive = isActive;

    return cat;
  } catch (err) {
    throw conflictIfDuplicate(err, 'Danh mục đã tồn tại');
  }
}
```

```js
import crypto from 'node:crypto';
import { Product } from '../models/Product.js';
import { Category } from '../models/Category.js';
import { AppError } from '../lib/errors.js';
import { slugify } from '../lib/slugify.js';
import { toObjectId } from '../lib/ids.js';

const escapeRegex = (s) => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');

const SORTS = {
  newest: { createdAt: -1 },
  price_asc: { price: 1 },
  price_desc: { price: -1 },
  rating: { ratingAvg: -1, ratingCount: -1 },
};

export async function search(query, { includeInactive = false } = {}) {
  const { q, category, brand, minPrice, maxPrice, sort, page, pageSize } = query;
  const filter = {};
  if (!includeInactive) filter.isActive = true;
  if (q) {
    const re = new RegExp(escapeRegex(q), 'i');
    filter.$or = [{ name: re }, { brand: re }];
  }
  if (category) filter.categoryId = toObjectId(category);
  if (brand) filter.brand = new RegExp(`^${escapeRegex(brand)}$`, 'i');
  if (minPrice !== undefined || maxPrice !== undefined) {
    filter.price = {};
    if (minPrice !== undefined) filter.price.$gte = minPrice;
    if (maxPrice !== undefined) filter.price.$lte = maxPrice;
  }
  const [items, total] = await Promise.all([
    Product.find(filter).sort(SORTS[sort]).skip((page - 1) * pageSize).limit(pageSize).lean(),
    Product.countDocuments(filter),
  ]);
  return { items, total, page, pageSize };
}

export async function getById(id, { includeInactive = false } = {}) {
  const product = await Product.findById(toObjectId(id)).lean();
  if (!product || (!includeInactive && !product.isActive)) {
    throw new AppError(404, 'NOT_FOUND', 'Không tìm thấy sản phẩm');
  }
  return product;
}

export async function listBrands() {
  const brands = await Product.distinct('brand', { isActive: true });
  return brands.sort((a, b) => a.localeCompare(b));
}

async function assertCategory(categoryId) {
  const valid = /^[0-9a-f]{24}$/i.test(categoryId);
  if (!valid || !(await Category.exists({ _id: categoryId }))) {
    throw new AppError(400, 'CATEGORY_NOT_FOUND', 'Danh mục không tồn tại');
  }
}

export async function create(data) {
  await assertCategory(data.categoryId);
  const slug = `${slugify(data.name)}-${crypto.randomBytes(3).toString('hex')}`;
  return Product.create({ ...data, slug });
}

export async function update(id, data) {
  if (data.categoryId) await assertCategory(data.categoryId);
  const patch = { ...data };
  if (data.name) patch.slug = `${slugify(data.name)}-${crypto.randomBytes(3).toString('hex')}`;
  const product = await Product.findByIdAndUpdate(toObjectId(id), patch, { new: true });
  if (!product) throw new AppError(404, 'NOT_FOUND', 'Không tìm thấy sản phẩm');
  return product;
}

export async function archive(id) {
  await update(id, { isActive: false });
}
```

```js
import { Cart } from '../models/Cart.js';
import { Product } from '../models/Product.js';
import { AppError } from '../lib/errors.js';
import { toObjectId } from '../lib/ids.js';

const getOrCreate = (userId) =>
  Cart.findOneAndUpdate(
    { userId },
    { $setOnInsert: { userId, items: [] } },
    { upsert: true, new: true },
  );

export async function getView(userId) {
  const cart = await getOrCreate(userId);
  const products = await Product.find({ _id: { $in: cart.items.map((i) => i.productId) } }).lean();
  const byId = new Map(products.map((p) => [String(p._id), p]));
  const items = cart.items.map((i) => {
    const p = byId.get(String(i.productId));
    const available = Boolean(p && p.isActive && p.stock >= i.quantity);
    return {
      productId: String(i.productId),
      name: p?.name ?? '(sản phẩm đã bị xóa)',
      price: p?.price ?? 0,
      imageId: p?.imageId ? String(p.imageId) : null,
      stock: p?.stock ?? 0,
      quantity: i.quantity,
      available,
      lineTotal: available ? p.price * i.quantity : 0,
    };
  });
  return { items, subtotal: items.reduce((sum, i) => sum + i.lineTotal, 0) };
}

async function loadActiveProduct(productId) {
  const product = await Product.findById(toObjectId(productId));
  if (!product || !product.isActive) throw new AppError(404, 'NOT_FOUND', 'Không tìm thấy sản phẩm');
  return product;
}

function assertStock(product, quantity) {
  if (quantity > product.stock) {
    throw new AppError(409, 'OUT_OF_STOCK', `Chỉ còn ${product.stock} sản phẩm "${product.name}"`);
  }
}

export async function addItem(userId, productId, quantity) {
  const product = await loadActiveProduct(productId);
  const cart = await getOrCreate(userId);
  const line = cart.items.find((i) => String(i.productId) === productId);
  const next = (line?.quantity ?? 0) + quantity;
  assertStock(product, next);
  if (line) line.quantity = next;
  else cart.items.push({ productId: product._id, quantity });
  await cart.save();
  return getView(userId);
}

export async function setQuantity(userId, productId, quantity) {
  const product = await loadActiveProduct(productId);
  assertStock(product, quantity);
  const cart = await getOrCreate(userId);
  const line = cart.items.find((i) => String(i.productId) === productId);
  if (!line) throw new AppError(404, 'NOT_FOUND', 'Sản phẩm không có trong giỏ');
  line.quantity = quantity;
  await cart.save();
  return getView(userId);
}

export async function removeItem(userId, productId) {
  await Cart.updateOne({ userId }, { $pull: { items: { productId: toObjectId(productId) } } });
  return getView(userId);
}
```

```js
import { Promotion } from '../models/Promotion.js';
import { AppError, conflictIfDuplicate } from '../lib/errors.js';
import { toObjectId } from '../lib/ids.js';

const invalid = () => new AppError(400, 'PROMO_INVALID', 'Mã giảm giá không hợp lệ hoặc đã hết hạn/lượt dùng');

const usableFilter = (code, subtotal) => {
  const now = new Date();
  return {
    code: code.trim().toUpperCase(),
    isActive: true,
    startsAt: { $lte: now },
    endsAt: { $gte: now },
    minOrder: { $lte: subtotal },
    $expr: { $lt: ['$usedCount', '$maxUses'] },
  };
};

export function computeDiscount(promo, subtotal) {
  const raw = promo.type === 'percent' ? Math.floor((subtotal * promo.value) / 100) : promo.value;
  return Math.min(raw, subtotal);
}

export async function validate(code, subtotal) {
  const promo = await Promotion.findOne(usableFilter(code, subtotal));
  if (!promo) throw invalid();
  return { code: promo.code, discount: computeDiscount(promo, subtotal) };
}

export async function consume(code, subtotal, session) {
  const promo = await Promotion.findOneAndUpdate(
    usableFilter(code, subtotal),
    { $inc: { usedCount: 1 } },
    { new: true, session },
  );
  if (!promo) throw invalid();
  return promo;
}

export async function release(code, session) {
  await Promotion.updateOne({ code, usedCount: { $gt: 0 } }, { $inc: { usedCount: -1 } }, { session });
}

export const list = () => Promotion.find().sort('-createdAt').lean();

export async function create(data) {
  try {
    return await Promotion.create(data);
  } catch (err) {
    throw conflictIfDuplicate(err, 'Mã giảm giá đã tồn tại');
  }
}

export async function update(id, data) {
  const promo = await Promotion.findByIdAndUpdate(toObjectId(id), data, { new: true });
  if (!promo) throw new AppError(404, 'NOT_FOUND', 'Không tìm thấy mã giảm giá');
```

```js
import mongoose from 'mongoose';
import { Cart } from '../models/Cart.js';
import { Product } from '../models/Product.js';
import { Order } from '../models/Order.js';
import { AppError } from '../lib/errors.js';
import { config } from '../config.js';
import * as promotionService from './promotionService.js';

export function toResult(order) {
  const obj = order.toObject ? order.toObject() : order;
  const paymentInfo = { method: obj.paymentMethod };
  if (obj.paymentMethod === 'bank') {
    paymentInfo.bank = config.bank;
    paymentInfo.transferContent = `DH${String(obj._id).slice(-8).toUpperCase()}`;
  }
  return { ...obj, paymentInfo };
}

export async function create(userId, input) {
  const { requestKey, paymentMethod, shippingAddress, promotionCode } = input;

  const existing = await Order.findOne({ userId, requestKey });
  if (existing) return { order: existing, created: false };

  const session = await mongoose.startSession();
  try {
    let order;
    await session.withTransaction(async () => {
      const cart = await Cart.findOne({ userId }).session(session);
      if (!cart || cart.items.length === 0) {
        throw new AppError(400, 'CART_EMPTY', 'Giỏ hàng trống');
      }

      const sorted = [...cart.items].sort((a, b) => String(a.productId).localeCompare(String(b.productId)));
      const lines = [];
      for (const item of sorted) {
        const product = await Product.findOneAndUpdate(
          { _id: item.productId, isActive: true, stock: { $gte: item.quantity } },
          { $inc: { stock: -item.quantity } },
          { new: true, session },
        );
        if (!product) {
          const current = await Product.findById(item.productId).session(session);
          throw new AppError(409, 'OUT_OF_STOCK', `Sản phẩm "${current?.name ?? item.productId}" không đủ hàng`);
        }
        lines.push({ productId: product._id, name: product.name, price: product.price, quantity: item.quantity });
      }

      const subtotal = lines.reduce((sum, l) => sum + l.price * l.quantity, 0);
      let discount = 0;
      let appliedCode;
      if (promotionCode) {
        const promo = await promotionService.consume(promotionCode, subtotal, session);
        discount = promotionService.computeDiscount(promo, subtotal);
        appliedCode = promo.code;
      }
      const shippingFee = config.shippingFee;

      [order] = await Order.create(
        [
          {
            userId,
            requestKey,
            items: lines,
            shippingAddress,
            subtotal,
            discount,
            shippingFee,
            total: subtotal - discount + shippingFee,
            promotionCode: appliedCode,
            paymentMethod,
            paymentStatus: paymentMethod === 'cod' ? 'unpaid' : 'pending',
          },
        ],
        { session },
      );
      await Cart.updateOne({ userId }, { $set: { items: [] } }, { session });
    });
    return { order, created: true };
  } catch (err) {
    if (err?.code === 11000) {
      const dup = await Order.findOne({ userId, requestKey });
      if (dup) return { order: dup, created: false };
    }
    throw err;
  } finally {
    await session.endSession();
  }
}
```

```js
import { toObjectId } from '../lib/ids.js';

const TRANSITIONS = {
  pending: ['confirmed', 'cancelled'],
  confirmed: ['shipping', 'cancelled'],
  shipping: ['delivered'],
  delivered: [],
  cancelled: [],
};

async function page(filter, { page: pageNo = 1, pageSize = 10 } = {}) {
  const [items, total] = await Promise.all([
    Order.find(filter).sort('-createdAt').skip((pageNo - 1) * pageSize).limit(pageSize).lean(),
    Order.countDocuments(filter),
  ]);
  return { items, total, page: pageNo, pageSize };
}

export const listMine = (userId, opts) => page({ userId }, opts);
export const listAll = ({ status, ...opts } = {}) => page(status ? { status } : {}, opts);

export async function getMine(userId, id) {
  const order = await Order.findOne({ _id: toObjectId(id), userId }).lean();
  if (!order) throw new AppError(404, 'NOT_FOUND', 'Không tìm thấy đơn hàng');
  return order;
}

export async function cancel(id, { userId } = {}) {
  const filter = { _id: toObjectId(id) };
  if (userId) filter.userId = userId;
  if (!(await Order.exists(filter))) throw new AppError(404, 'NOT_FOUND', 'Không tìm thấy đơn hàng');

  const session = await mongoose.startSession();
  try {
    let cancelled;
    await session.withTransaction(async () => {
      cancelled = await Order.findOneAndUpdate(
        { ...filter, status: { $in: ['pending', 'confirmed'] }, paymentStatus: { $ne: 'paid' } },
        { status: 'cancelled' },
        { new: true, session },
      );
      if (!cancelled) {
        throw new AppError(409, 'CANNOT_CANCEL', 'Không thể hủy đơn hàng ở trạng thái này');
      }
      for (const item of cancelled.items) {
        await Product.updateOne({ _id: item.productId }, { $inc: { stock: item.quantity } }, { session });
      }
      if (cancelled.promotionCode) await promotionService.release(cancelled.promotionCode, session);
    });
    return cancelled;
  } finally {
    await session.endSession();
  }
}

export async function updateStatus(id, next) {
  const order = await Order.findById(toObjectId(id));
  if (!order) throw new AppError(404, 'NOT_FOUND', 'Không tìm thấy đơn hàng');
  if (!TRANSITIONS[order.status].includes(next)) {
    throw new AppError(409, 'INVALID_TRANSITION', `Không thể chuyển từ ${order.status} sang ${next}`);
  }
  if (next === 'cancelled') return cancel(id);
  if (next === 'confirmed' && order.paymentMethod === 'bank' && order.paymentStatus !== 'paid') {
    throw new AppError(409, 'PAYMENT_REQUIRED', 'Đơn chuyển khoản cần xác nhận đã thanh toán trước');
  }
  const patch = { status: next };
  if (next === 'delivered') patch.deliveredAt = new Date();
  const updated = await Order.findOneAndUpdate({ _id: order._id, status: order.status }, patch, { new: true });
  if (!updated) throw new AppError(409, 'CONFLICT', 'Đơn hàng vừa được cập nhật, vui lòng tải lại');
  return updated;
}

export async function confirmPayment(id) {
  const updated = await Order.findOneAndUpdate(
    { _id: toObjectId(id), paymentStatus: { $in: ['unpaid', 'pending'] }, status: { $ne: 'cancelled' } },
    { paymentStatus: 'paid' },
    { new: true },
  );
  if (!updated) {
    throw new AppError(409, 'CANNOT_CONFIRM_PAYMENT', 'Không thể xác nhận thanh toán cho đơn này');
  }
  return updated;
}
```

```js
import { Review } from '../models/Review.js';
import { Order } from '../models/Order.js';
import { Product } from '../models/Product.js';
import { AppError } from '../lib/errors.js';
import { toObjectId } from '../lib/ids.js';

export async function list(productId, { page, pageSize }) {
  const filter = { productId: toObjectId(productId) };
  const [rows, total] = await Promise.all([
    Review.find(filter).sort('-createdAt').skip((page - 1) * pageSize).limit(pageSize)
      .populate('userId', 'fullName').lean(),
    Review.countDocuments(filter),
  ]);
  const items = rows.map(({ userId, ...r }) => ({ ...r, user: { fullName: userId?.fullName ?? 'Người dùng' } }));
  return { items, total, page, pageSize };
}

async function recomputeRating(productId) {
  const [agg] = await Review.aggregate([
    { $match: { productId } },
    { $group: { _id: null, avg: { $avg: '$rating' }, count: { $sum: 1 } } },
  ]);
  await Product.updateOne(
    { _id: productId },
    { ratingAvg: agg ? Math.round(agg.avg * 10) / 10 : 0, ratingCount: agg?.count ?? 0 },
  );
}

export async function upsert(userId, productId, { rating, comment }) {
  const pid = toObjectId(productId);
  if (!(await Product.exists({ _id: pid }))) throw new AppError(404, 'NOT_FOUND', 'Không tìm thấy sản phẩm');
  const purchased = await Order.exists({ userId, status: 'delivered', 'items.productId': pid });
  if (!purchased) {
    throw new AppError(403, 'NOT_PURCHASED', 'Bạn chỉ có thể đánh giá sản phẩm đã nhận hàng');
  }
  const existing = await Review.findOne({ userId, productId: pid });
  const review = await Review.findOneAndUpdate(
    { userId, productId: pid },
    { rating, comment },
    { upsert: true, new: true, setDefaultsOnInsert: true },
  );
  await recomputeRating(pid);
  return { review, created: !existing };
}
```

```js
const escapeRegex = (s) => s.replace(/[.*+?^${}()|[\]\\]/g, '\\$&');

export async function list({ q, page, pageSize }) {
  const filter = {};
  if (q) {
    const re = new RegExp(escapeRegex(q), 'i');
    filter.$or = [{ email: re }, { fullName: re }];
  }
  const [users, total] = await Promise.all([
    User.find(filter).sort('-createdAt').skip((page - 1) * pageSize).limit(pageSize),
    User.countDocuments(filter),
  ]);
  return { items: users.map(toDTO), total, page, pageSize };
}

export async function setStatus(actingAdminId, id, isActive) {
  if (String(actingAdminId) === id) {

  if (!user) throw new AppError(404, 'NOT_FOUND', 'Không tìm thấy người dùng');
```

```js
import { Order } from '../models/Order.js';

export async function revenue({ from, to }) {
  const byDay = await Order.aggregate([
    { $match: { status: 'delivered', paymentStatus: 'paid', deliveredAt: { $gte: from, $lte: to } } },
    {
      $group: {
        _id: { $dateToString: { format: '%Y-%m-%d', date: '$deliveredAt', timezone: 'Asia/Ho_Chi_Minh' } },
        revenue: { $sum: { $subtract: ['$total', '$shippingFee'] } },
        orders: { $sum: 1 },
      },
    },
    { $sort: { _id: 1 } },
    { $project: { _id: 0, date: '$_id', revenue: 1, orders: 1 } },
  ]);
  return {
    revenue: byDay.reduce((s, d) => s + d.revenue, 0),
    orderCount: byDay.reduce((s, d) => s + d.orders, 0),
    byDay,
  };
}
```

```markdown
## Architecture

Backend layering is strict: `routes → controllers → services → models`.
- Routes only bind URL + middleware (`authenticate`, `requireAdmin`) to a controller.
- Controllers parse input with zod (`validators/`), call one service function, set status/JSON. No business logic, no model access.
- Services own all business rules and transactions, take plain arguments (never `req`/`res`), and throw `AppError(status, code, message)`. `middleware/errorHandler.js` turns those and `ZodError` into `{code, message, fieldErrors?}`.
- Authorization is enforced in the backend (JWT in httpOnly `token` cookie; `authenticate` re-checks `isActive` on every request). Frontend route guards are UX only.

Order integrity (`services/orderService.js`) is the core invariant set: one `withTransaction` covers stock deduction (conditional `$gte` update, lines sorted by product id), promotion consumption (conditional `usedCount < maxUses`), order creation and cart clearing; `(userId, requestKey)` unique index makes replays idempotent; cancel flips status with a conditional update so stock/promo are restored exactly once. `paymentStatus` is separate from `status`; only an admin marks `paid`, and revenue counts only `delivered` + `paid` orders by `deliveredAt`, excluding shipping fee.

Tests hit a real MongoDB (no DB mocks) through supertest; files run serially (`--test-concurrency=1`) and share `webbanhang_test`, cleaned by `resetDb()` in `tests/helpers.js`.
```
