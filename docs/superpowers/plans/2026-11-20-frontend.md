# Frontend Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the complete Next.js frontend (App Router + Tailwind CSS + Framer Motion) for the tech e-commerce site, connecting seamlessly to the existing Express 5 + MongoDB backend API, featuring the flagship UI design language (Mega-Menu, Scroll-Shrink Hero, Zero-reload dynamic tabs, Scroll Reveal animations, and dark-mode minimalist auth).

**Architecture:** Next.js (App Router, JavaScript ESM) running on port 3000. It proxies all `/api/*` calls to the backend running on `http://localhost:4000` via `rewrites` in `next.config.mjs`, ensuring httpOnly cookie authentication works seamlessly without CORS issues.

**Tech Stack:**
- Next.js 15 (App Router, JavaScript ESM)
- Tailwind CSS 3/4 + PostCSS + Autoprefixer
- `framer-motion` (for smooth mega-menu dropdowns, scroll-shrink banner, and scroll reveal)
- `lucide-react` (icons)
- Existing Backend: Express 5 + MongoDB on port 4000
